# sujithvs.com

Personal site of Sujith Surendran, built with Jekyll and the [Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes) theme on GitHub Pages.

- Page content: `index.md`
- Site settings, sidebar profile and theme skin: `_config.yml`
- Top navigation: `_data/navigation.yml`

## Local preview

```sh
bundle install
bundle exec jekyll serve
```
